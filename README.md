# 🎮 React Tic-Tac-Toe Game

A simple yet powerful Tic-Tac-Toe (Noughts and Crosses) game built with **React**. This project is designed to help beginners understand key React concepts such as **state management**, **component-based architecture**, **immutability**, and **lifting state up**.

## 🚀 Features

- Two-player mode (Player X and Player O)
- Dynamic player name editing
- Game board rendering based on current state
- Win and draw detection with game over screen
- Game log tracking turns
- Game reset functionality
- Clean UI with conditional rendering

## 🛠️ Technologies Used

- React (with Hooks)
- JavaScript (ES6+)
- CSS (utility classes)

## 🧠 Core Concepts Practiced

- **Immutability**: Game board is cloned before being updated.
- **Derived State**: Active player and game board are computed based on turns.
- **Conditional Rendering**: Game over screen appears only if there's a win or draw.
- **Event Handling**: Board clicks, name changes, and reset button.
